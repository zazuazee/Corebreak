# COREBREAK

COREBREAK é um jogo arcade competitivo de arena em visão superior, focado em grid, ondas de energia, destruição de obstáculos e combate rápido em partidas curtas.

## Visão geral

- Engine: Godot 4
- Linguagem: GDScript
- Plataforma alvo: Android / iOS
- Modo inicial: single-player contra IA
- Orientação: portrait

## Objetivo do MVP

O MVP inicial implementa a base funcional do gameplay:

- arena em grid;
- movimentação do jogador;
- obstáculos quebráveis;
- Core do jogador;
- onda de energia em 4 direções;
- dano e derrota/vitória;
- IA básica;
- estrutura pronta para expansão.

## Estrutura do projeto

- `docs/` — documentação e roteiro do jogo
- `scenes/` — cenas do Godot
- `scripts/` — lógica do jogo em GDScript
- `assets/` — sprites, áudio e recursos visuais

## Como rodar

1. Instale o Godot 4.
2. Abra esta pasta como projeto Godot.
3. Execute a cena principal da arena.

## Desenvolvimento

Este repositório está sendo estruturado para suportar a entrega incremental do MVP do COREBREAK, conforme o GDD e o prompt de autopilot do projeto.
